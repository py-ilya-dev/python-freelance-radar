# 📡 Python Freelance Radar Bot (Aiogram 3 + BeautifulSoup4 + SQLite)

Автоматизированный асинхронный бот-радар для мониторинга свежих заказов на биржах фриланса (Хабр Фриланс) с фильтрацией по ключевым словам, цене и моментальным уведомлением администратора в Telegram.

## 🕹️ Уникальные фичи проекта:
- **Умный парсинг в фоне:** Автономный скрипт проверяет биржу по расписанию 24/7 без участия пользователя.
- **Тихий режим:** Фоновая проверка не спамит сообщениями «заказов нет» и присылает уведомление только при обнаружении целевого лида.
- **Интерактивный пульт:** Ручная кнопка `проверить! 🔍` для моментального сканирования биржи прямо «здесь и сейчас».
- **Динамический таймер:** Кнопка настройки времени чека позволяет менять интервал проверки (в минутах) на лету через Машину состояний (FSM).
- **Защита от дублей:** Интеграция базы данных `SQLite` гарантирует, что каждый заказ прилетит в личку строго один раз.
- **Безопасность админ-панели:** Жесткая проверка `user_id` на уровне кода — команды управления и рассылки доступны только владельцу.

## 🛠️ Стек технологий:
- Python 3.11+
- Aiogram 3.x (Асинхронный фреймворк)
- BeautifulSoup4 & Requests (Парсинг HTML)
- SQLite3 (Локальная база данных)
- Базовый деплой на облачный хостинг Amvera Cloud
